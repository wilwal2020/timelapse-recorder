Timelapse Recorder — redesign options

Four directions for the panel. Every option keeps the same tabs, the same sections in the same order, and the same controls (record/pause, auto record, export, live preview, reference layer Normal/Reference, library actions, settings). Only the look changes. Each is shown as it would appear docked in Photoshop at about 284 px wide, while recording.

A · NativeB · StudioC · SoftD · Compact

A · Native looks like part of Photoshop

Uses Photoshop's own panel style: no boxes around sections, just thin dividers and plain headings. It has underline tabs, a blue accent and Photoshop-style switches, and the stats sit in one clean row. It's the calmest option and fits in with the Layers and Properties panels.

B · Studio the timer is the star

A dark "hero" box at the top shows the work timer in big numbers, with a round record button. The button is green while recording and grey while paused, and the green outline around the box shows at a glance that you're live. Export is a strong violet button. The reference layer card gets a green bar on its left when the layer is a reference. This one is the most distinctive and feels most like an app.

C · Soft rounded and friendly

This is closest to the current design, but softer: bigger corner radii, a tall pill-shaped record button, and a bit more breathing room. Each stat tile has a small coloured marker, and the colours are muted: teal for toggles, blue for export, green for recording. It's friendly and modern without feeling out of place in Photoshop.

D · Compact everything in a short panel

Made for a small panel height (you lowered the minimum to 100 px). Auto record moves up next to the tabs. Record and Export share one row. The document name, frame count, timer and disk use fit on one line, and the reference layer is a single row. The whole Record tab is about 170 px tall. The Library shows each recording as one line with a coloured status dot: green is recording, grey-green is exported, yellow is not exported, grey is empty.

All four only use things Photoshop's plugin panels draw reliably: flex rows and columns spaced with margins (no gap), exact corner radii (no 999px), flat colours and 1 px borders (no shadows or gradients), and shapes made from styled boxes instead of icon fonts. Design B's round record button uses an outline ring, and Photoshop might not draw that part. If it doesn't, it would be swapped for a plain border. The colours and details of any option can be mixed: for example, B's hero timer on top of A's plain layout.
